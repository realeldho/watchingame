# WatchInGame 🎬

### YouTube directly inside Minecraft

Watch YouTube videos without leaving Minecraft.

WatchInGame is a Fabric mod for Minecraft 1.21.11 that brings an in-game YouTube player to your Minecraft client.

## ✨ Features

- 🎥 Watch YouTube videos inside Minecraft
- ▶️ Play / Pause
- ⏪ Rewind
- ⏩ Forward
- 🔊 Volume control
- 📍 Video timeline / seeking
- ⌨️ Open WatchInGame with the `Y` key
- 🖥️ Watch while keeping Minecraft around the player
- 🎮 Works in singleplayer and multiplayer
- ⚡ Lightweight and optimized
- 🎨 Clean Minecraft-style interface

## 🎮 Controls

| Key / Action | Function |
|---|---|
| `Y` | Open WatchInGame |
| `ESC` | Close the video screen |
| Mouse | Use video controls |

## 📦 Installation

### Requirements

- Minecraft **1.21.11**
- **Fabric Loader**
- **Fabric API**
- **MCEF Modern**

### Installation

1. Install Fabric for Minecraft 1.21.11.
2. Install Fabric API.
3. Install MCEF Modern.
4. Place the WatchInGame `.jar` file into your `mods` folder.
5. Launch Minecraft.
6. Press `Y` to open WatchInGame.
